# 🎯 GuessMaster: A Python-based Number Guessing Game

## 📌 Project Description
GuessMaster is a simple yet interactive command-line based number guessing game built using Python. The game generates a random number between 1 and 100, and the player has to guess the correct number based on hints.

---

## 🚀 Features
- 🎲 Random number generation
- 📥 User input handling
- 🔼 Hint system (Too High / Too Low)
- 🔁 Unlimited attempts until correct guess
- ⚠️ Basic error handling

---

## 🛠️ Technologies Used
- Python
- Visual Studio Code (VS Code)
